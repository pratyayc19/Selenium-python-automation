# Selenium Python Automation

A structured Python Selenium automation repository containing laboratory assignments, milestone-wise practical work, a Selenium automation capstone project, and technical certification documents.

This repository was developed as part of the Python Automation laboratory coursework and demonstrates progressive learning from fundamental Selenium concepts to structured test automation using PyTest, Unittest, Page Object Model, data-driven testing, configuration management, logging, failure handling and HTML reporting.
